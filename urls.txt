# urls.txt —— 批量下载列表样板（UTF-8 编码，无 BOM）
# =============================================================================
# 每行一个任务，语法：
#
#     <视频URL> [输出文件名]
#
# 规则说明：
#   1. URL 是「第一个空白符之前」的内容，后面所有内容都当作输出文件名，
#      所以输出文件名里可以直接包含空格，不需要加引号。
#      例： https://b23.tv/AbCdEf   我的音乐/晴天 - live版.mp3
#   2. 省略输出文件名时，用 -o 的基名自动编号：output_1.mp3、output_2.mp3 ...
#      例： audio_extractor.exe -l urls.txt -o 收藏/周杰伦 -b 320
#           => 收藏/周杰伦_1.mp3、收藏/周杰伦_2.mp3 ...
#   3. 以 # 开头的行为注释，空行也会被忽略。
#   4. 输出文件名支持中文和子目录，目录不存在会自动创建。
#   5. 扩展名决定输出格式（.mp3 / .wav）；也可用 -f mp3|wav 统一指定，
#      此时文件名缺失/扩展名不对时会自动补成对应后缀。
#   6. 本文件的役割仅在批量模式：audio_extractor.exe -l urls.txt -b 320
# =============================================================================
