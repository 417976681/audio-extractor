浏览器插件 · 抓歌到曲库

检查扩展文件…

安装后，浏览器里正在播放的歌曲会出现在插件面板中，点一下 「提取到全部曲目」，它就会自动下载、转成 MP3 并进入本播放器的曲库。 也可以在任意链接上右键 → 提取该链接到曲库。

—
  1. 在 Chrome / Edge 地址栏输入 chrome://extensions 并回车（Edge 是 edge://extensions）。
  2. 打开右上角（Edge 在左侧）的 开发者模式。
  3. 点击 加载已解压的扩展程序，选择上面复制目录里的 extension 文件夹。
  4. 到任意音乐网页播放歌曲，点浏览器工具栏里的紫色音符图标即可抓取。
插件只与本机服务通信（默认 http://127.0.0.1:8080），不经过任何第三方。
